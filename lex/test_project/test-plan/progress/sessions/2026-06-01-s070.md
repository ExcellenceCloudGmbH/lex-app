**`AuditLogStatus.status` now reflects user cancellation explicitly — added `"cancelled"` as a distinct audit-status value alongside the pre-existing `"success"` / `"failure"` / `"aborted"` strings.** Follow-up to PR #552 (Session 69, ABORTED/CANCELLED state split). Question raised by the developer: "is the audit log status also reflecting the cancelled status, or can we not do it?" — yes, we can. `AuditLogStatus.status` is a free-form `CharField(max_length=20)` with no choices restriction, and the startup-reset path already writes `audit_status="aborted"` (custom string, non-success-non-failure), so the precedent for outcome-specific audit-status strings exists. Without this change, a user-cancelled run recorded `audit_status="failure"` and was indistinguishable from a real crash in the compliance trail — the very mislabelling Session 68 set out to fix at the calc-state level but didn't push all the way through the audit row. **Source (2 files, 3 audit-row writers):** (1) `lex/lex_app/celery_tasks.py` `CallbackTask._update_model_status` finally — terminal-state → audit-status mapping widened from binary (`success`/`failure`) to ternary: SUCCESS → `"success"`, CANCELLED → `"cancelled"`, ERROR / anything else → `"failure"`. (2) `lex/core/models/CalculationModel.py` `execute_calculation_sync` CANCELLED-branch finally — flipped `audit_status="failure"` → `"cancelled"` (error_message default "Calculation cancelled by user" preserved). (3) `CalculationModel.calculate_hook` `_pending_terminal_audit` (the deferred audit dict written after the hook's exception branch) — `audit_status` now picks `"cancelled" if is_cancellation else "failure"`, mirroring the sync branch + the worker callback. Resulting four-value namespace for `AuditLogStatus.status` after this row: `"success"` (SUCCESS), `"cancelled"` (user cancel via `CalculationModel.cancel()` or `CalculationCancelled`), `"aborted"` (startup reset of crashed-worker IN_PROGRESS row), `"failure"` (ERROR / unrecognised). Plus the default `"pending"` written by `log_object_*` before the terminal sweep — five total.
