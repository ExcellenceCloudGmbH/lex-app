# lex.ui: a private result, a job limit, a form result kept across visits (1dv-1dx)

`ui.private()` keeps a state field's value in the server process's memory only, bound to its tab and user, for a
while (batch [1dv](../../clusters/01-init/batches.md)); `@ui.job(limit=N)` refuses a press beyond N runs at once
(batch [1dw](../../clusters/01-init/batches.md)); `ui.form(keep=True)` shows a form's result again after a visit away
(batch [1dx](../../clusters/01-init/batches.md)). Test 1.783 follows: `ui.private` is a public name.
