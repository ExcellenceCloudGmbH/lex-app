An independent review of lex.ui's frame, calculation pages and tables (review 2), applied. Privacy: the next
user of a browser tab starts without the last user's answers, and lex-app's sign-out gives the tab a new client
token (1.1100-1.1102); a searched field's matches are never stored (1.1103). Access: a page's tables read only for
users its `requires=` grants (1.1104); a calculation's handlers require the page that builds it (1.1105).
Robustness: every table restores its rows after a reconnect, routed or not (1.1106); a calculation is started once
(1.1107); the frame's decision and a field's search sent in a loop take one worker (1.1108-1.1109); a rows table
reads its handler once (1.1114). Readability: `ui.frame(nav=)` is a dict, `ui.reflex_page(visible=)`,
`denied_as_missing=`, a frame value fixed or a function of the user, `ui.testing.lex_api` checks the user
(1.1110-1.1113). Minor items: 1.1115-1.1122. Every new scenario is appended to its batch in
[batches.md](../../clusters/01-init/batches.md); the pages design spec's 6.22 lists them under "Review 2".
