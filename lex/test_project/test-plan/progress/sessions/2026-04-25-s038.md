**Sub-clusters 1j / 1k / 1l landed — Keycloak client safety pre-flight (mocked + real-Keycloak integration).** Customer-facing risk closed: `lex init` will now refuse to mutate a non-DEVELOPMENT or non-confidential Keycloak client. Without this gate, an operator who points the framework at a STANDARD/production client by accident silently rewrites its resources, policies, and permissions — the very accident that motivated the controller's `is_confidential` + `client_type="DEVELOPMENT"` invariants in the first place. Three new test files + one framework feature: **(framework, `lex/lex_app/management/commands/init.py`)** added module-level constant `KEYCLOAK_DEV_REDIRECT_HOST = "localhost"` and helper `_redirect_uris_indicate_development(uris)` which uses `urllib.parse.urlparse(...).hostname` (case-insensitive `== "localhost"`) so look-alike hosts (`localhost.example.com`) and loopback IPs (`127.0.0.1`) do NOT count — non-string entries are skipped silently. Added `KeycloakSyncManager.verify_client_is_safe_for_init()` which fetches the client representation via `admin.get_client(client_uuid)` and raises `CommandError` (chained on the underlying exception when relevant) for any of: empty `client_uuid`, network failure, non-dict response, missing `publicClient` flag, `publicClient is True`, missing/malformed/empty `redirectUris`, or no localhost redirect. Returns the rep on success so callers can avoid a second round-trip.
