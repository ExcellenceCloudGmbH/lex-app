**Showcase report — dual-template rewrite (branded + scalable).** Three focused upgrades to the report pipeline, all at the builder layer — no change to the CI contract or secrets list. (1) **Brand**: palette rebased on the Excellence Cloud logo — primary navy `#283067` (hexagon) and accent teal `#24b6bb` (the "=" band + "CLOUD" wordmark), with a 4-px teal divider between the navy header and the body. Default brand string flipped from `"LEX Platform"` to `"Excellence Cloud"`; `SHOWCASE_BRAND` repo-variable override unchanged. The header embeds `images/dark-lex-logo.svg` via **cairosvg** (new dep, added to the CI pip install alongside weasyprint/sendgrid) — SVG is rasterised to a 520-px-wide PNG, base64-encoded, and inlined as a data URI so Outlook and corporate gateways that strip `<svg>` still render the wordmark; falls back to a text wordmark if cairosvg is unavailable or the file is missing. WeasyPrint picks the PNG up for the PDF from the same data URI, giving byte-identical rendering. (2) **"What we test and why" → PDF only**: per user's explicit instruction, the glossary section is removed from the email body entirely and lives only in the PDF. The email footer carries a one-line hint ("The attached PDF contains the full report including the 'What we test and why' glossary.") so the reader knows where to find it. (3) **Scalable email layout**: the email was one fat card per test, which would explode on the inbox if we ever add more tests. Split into two functions — `render_email_html` (compact) and `render_pdf_html` (detailed). Email strategy: **failures first as expanded cards** under a red "Needs attention (N)" heading, then **passes as one-line rows** under a green "Working (N)" heading — 14px per pass, not a 200px card. Verdict band now shows a counts line ("2 of 2 capabilities passing") so scannable at a glance. PDF keeps the detailed per-test card + glossary. Both layouts share the header band / verdict band / footer, so the brand is consistent. Local verification: 2 tests all-green → email 14.6 KB, PDF 24.6 KB; 1 failure → email 15.9 KB (tiny bump from the expanded failure card), PDF 24.9 KB. Logo base64 embed confirmed (1 data URI in both). Glossary appears in PDF only — email's sole "What we test and why" occurrence is the footer hint pointing at the PDF (grep-verified, line 129). CI YAML updated to `pip install "weasyprint>=61" "cairosvg>=2.7" "sendgrid>=6.11"`.
