**Showcase report — CID logo + tabular layout.** Two user-reported issues. (1) **Logo invisible in delivered email**: Session 27 used a base64 `data:image/png` URI which WeasyPrint renders fine for PDFs but which SendGrid and most major email clients (Gmail, Outlook, corporate relays) strip from `<img src>` to prevent tracking/spam — so the wordmark rendered in the PDF but came through empty in the actual inbox. Confirmed the two excellence-cloud.com data URIs the user pulled (light + dark mode) match the committed SVGs at `images/lex-logo.svg` / `images/dark-lex-logo.svg` — the dark-mode white-text wordmark is the right pick for our navy header, no asset change needed. **Fix**: dual-source the logo. The builder now emits a separate `logo.png` alongside `report.html` / `report.pdf`; the email HTML uses `<img src="cid:logo">` (a Content-ID reference that points at an inline MIME attachment); the sender attaches `logo.png` via SendGrid's `Attachment(..., Disposition("inline"))` + `ContentId("logo")` so the `cid:` reference resolves at the recipient's end. The PDF continues to embed the PNG as a `data:` URI (PDFs don't have CIDs). Email size dropped 14.6 KB → 8.9 KB as a side-effect because the logo bytes no longer inline in the HTML body. (2) **Both layouts redesigned as proper data tables**: the previous "card per test" / "one-line row per pass" split worked but didn't feel like an executive report. Collapsed both into a **single three-column table** — `Status | Capability | Runtime` — with an uppercase-letterspaced header row tinted in the brand background and subtle alternating-row zebra striping (`#fafbfd` on odds). Each failing row gets a `#fff5f6` red tint plus a secondary full-width row directly underneath carrying the "what it means if broken" paragraph in `#b71c1c`, so the eye is dragged straight to the problem without breaking the scan pattern. PDF variant extends the expansion to every row (success → "what this proves", failure → "what it means if broken") and still renders the "What we test and why" glossary below the table — unchanged from Session 27. Infra updates: CI workflow `Build customer report` step passes `--out-logo logo.png`, the `Upload report artefact` step uploads all three (`report.html` + `report.pdf` + `logo.png`), the `Send customer email` step passes `--logo-path logo.png --logo-cid logo` through to the sender. Default brand on both build + send steps flipped from `"LEX Platform"` to `"Excellence Cloud"`.
