# Lex Local Example Context Files

This folder stores repository-local reference files for Lex model patterns.

## Primary references

- `LexModelExplain.py`
- `CalculationModelExplain.py`

## Compatibility-name aliases

- `LexModuleExample.py`
- `CalculationModelxplain.py`

## Intended usage

- Use these files as context artifacts for LLM planning/implementation sessions.
- Treat them as pattern references for hooks, permissions, status transitions, and report flows.
- Do not assume they are import-ready modules for target project packages.
- Treat Lex framework classes shown here (`LexModel`, `CalculationModel`) as preimplemented internals.
- Do not copy/recreate these base class internals into project UML, pseudocode, or implementation plans.
