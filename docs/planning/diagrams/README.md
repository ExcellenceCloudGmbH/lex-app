# Diagram Artifacts

This folder contains handbook examples only.
Do not store run outputs here.

## Suggested files per run

- `YYYY-MM-DD-uml.mmd`
- `YYYY-MM-DD-er.mmd`

Write these files under `plans/<run-id>/diagrams/`.

## Rules

- Keep Mermaid source as the canonical version.
- Prefer plain Mermaid fenced blocks in the step note for Obsidian rendering.
- Avoid wrapping Mermaid with HTML containers (`<details>`, `<summary>`, `<div>`, etc.).
- Never overwrite approved diagrams without bumping version/date.
- Link final artifacts from the corresponding run note.
