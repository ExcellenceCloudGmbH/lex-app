## Main changes

- **An embedded dashboard no longer logs you out after four hours.** When a Streamlit dashboard is embedded in the app, its session had a hard four-hour ceiling and no way to extend itself, so a long working session ended in a re-login. The session now publishes when it expires, which lets it be renewed quietly before it does.

- **A lapsed embedded session no longer shows "refused to connect".** When an embedded session did expire, the app sent the login page into the embedded frame — which browsers refuse to display, for good reason. The app now detects that it is embedded and breaks out to a full-page login instead of showing a blank error.

- **Set up AI assistance in any editor.** Wiring a project up for AI assistance previously worked only for GitHub Copilot inside a JetBrains IDE. It now supports any of the agentic editors known to the assistant tooling, selectable on the command line or from a multi-select picker that pre-selects the tools it finds on your machine. New editors arrive with an assistant update and need no framework upgrade.

## Bug fixes

- **A calculation no longer looks like a person edited the record.** "Last edited by" and "last edited at" are meant to record the last *human* edit, but two calculation-triggered saves were stamping them. A completed run put the old value back, which hid the problem — but a run interrupted part-way, by a restart or a failure, left the record claiming it had been edited by whoever started the calculation. Calculation-owned saves no longer touch those fields at all, so correctness no longer depends on a run finishing.

## Internal

- **AI assistant compatibility.** The framework's assistant server used a copy of a library that ships inside the AI SDK, and that copy is removed in the SDK's next major version — which the assistant tooling installs into the same environment. Left alone this would have become a startup failure on a customer's next upgrade rather than a deprecation warning. Verified against the pre-release versions rather than assumed.
- **Design tokens available in Python**, generated from the shared design token package with a CI check that keeps the copy fresh.
- **Release-note and changelog automation** — the first version of the pipeline that drafts these notes.
- Container images can now be built from a branch or commit without first publishing a release, which makes testing an unreleased branch in a cluster a one-step operation.

**No frontend changes in this release.** The interface is unchanged from `v2.1.4`.
