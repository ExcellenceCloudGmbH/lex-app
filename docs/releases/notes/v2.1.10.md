## Bug fixes

- **An embedded dashboard stops failing after hours open.** A flood of authorization
  failures, a slow first load and intermittent page errors were one bug: the dashboard's
  credentials were captured once, when the page connected, and nothing renewed them.
  Sessions now renew ahead of expiry, and an expired one returns you to the page you were
  on rather than the home page.

- **An instance no longer needs a new setting to start.** Session signing keys derive from
  configuration every deployment already has, stable across restarts and identical on every
  replica — so dashboard sessions survive a redeploy instead of logging everyone out. An
  explicit `SESSION_SECRET` still wins where set.

- **A platform administration role no longer grants access to business applications.** The
  role is excluded from application authorization, and policies older versions minted for
  it — never removed once created — are purged when permissions synchronise.

**The interface changed only for the session fix above** — its browser-side half ships in
this release's interface bundle. Nothing else in the interface differs from `v2.1.4`.

---

**Upgrade note:** no action needed. No migrations, no configuration changes, and no new
environment variable for the session fix above.
