## Bug fixes

- **A removed file stays removed.** Clearing a file or image field in the edit form and saving brought the old file back. Reported by a customer on 2026-07-13. A multipart update had no way to express "this file is gone" — leaving the field out means "keep it", so the cleared value never reached the record and the previous file survived the save. Clearing a file field now removes the stored file, while replacing a file or leaving one untouched behaves exactly as before. This covers PDF and spreadsheet fields as well as plain file and image fields.
