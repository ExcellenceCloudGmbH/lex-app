## Main changes

- **A second AI chat can have a checkout of its own.** `lex ai-worktree` prepares an isolated working copy, so starting a second chat is one command followed by one chat — rather than starting the chat, being told the working tree is busy, and opening another.

- **New AI commands arrive without a framework upgrade.** The commands live in the assistant package, which the assistant's own update command already installs — but adding one still required a new framework release before it could be reached. Any `lex ai-…` command the framework does not define itself is now handed straight to the installed assistant, which owns its options, help text and exit code. Adding a command is an assistant release and nothing more, so you no longer need to take a whole framework upgrade to reach one.

## Internal

- The documented AI command table now describes what the assistant provides rather than defining it, so the two cannot drift apart.
- A bundled documentation folder that is no longer needed has been removed.

**No frontend changes in this release.** The interface is unchanged from `v2.1.4`.
